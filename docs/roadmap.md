# 開発の計画

最終更新: 2026-10-08

サクラエディタの仕様を一度に取り込むと破綻するので、メモ帳相当の基本機能から作り、あとでサクラの機能をまとめて実装する（[ADR-0001](adr/0001-project-approach.md)）。

## フェーズ

| Phase | 内容 | 完了の目安 |
|---|---|---|
| 0. 土台 | 決定事項の記録、ライセンス、UI の試作、Cargo ワークスペースと CI | UI フレームワークが決まり、3 OS の CI が通る |
| 1. メモ帳相当 | 開く・保存（文字コード、BOM、改行コード）、編集、Undo/Redo、IME、検索・置換（文字列のみ）、行番号、タブ・全角空白・改行マークの表示、折り返し、サクラのキー割り当てとメニュー | 日常のメモ書きに使える |
| 2. 巨大ファイル | 2GB を超えるファイルを範囲ごとに読む方式、改行位置のバックグラウンド走査、ファイル全体を順に読みながらの検索 | 10GB のファイルを開いてすぐスクロールできる |
| 3. 正規表現 | Onigmo の組み込み、サクラと同じ検索・置換オプション | bregonig との互換テストに合格する |
| 4. マクロ・プラグイン | プラグインホスト、Python / Ruby 用ライブラリ、イベント、キーマクロの記録 | Python と Ruby でマクロが書ける |
| 5. 並列実装 | サクラの機能台帳から、複数のサブエージェントで機能をまとめて実装する。サクラ設定の取り込みもここで扱う | — |

## Phase 1 から用意しておく差し込み口

実装は後のフェーズでも、入口は Phase 1 で作る。

- 元データの持ち方: 「全部読む」と「範囲ごとに読む」を差し替えられる形にする（[ADR-0005](adr/0005-text-buffer-and-large-files.md)）
- 検索エンジン: Phase 1 は文字列検索だけ。Phase 3 で Onigmo を差し込む（[ADR-0006](adr/0006-regex-engine.md)）
- コマンドとイベント: すべての操作をコマンドにする（[ADR-0008](adr/0008-commands-and-keybindings.md)）
- 選択範囲: 矩形選択を扱える形にする

## Phase 5（並列実装）に向けた準備

- 1 コマンド 1 ファイルにし、登録は自動で集める
- 編集コマンドのテストは、カーソル位置付きのテキストで期待値を書く形式にする（形式は Phase 1 で決める）
- サクラの機能台帳（コマンド・設定・ヘルプを、依存関係と優先度付きで一覧にしたもの）を作る
- バッファ、カーソル・選択、検索の API を Phase 5 の前に固める
- エージェントごとに別の git worktree で作業し、テストとレビューを通ったものだけを取り込む
