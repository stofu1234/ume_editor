# ADR-0001: プロジェクトの方針と進め方

- 状態: 決定
- 日付: 2026-10-08

## 背景

サクラエディタは Win32 と C++ で書かれた Windows 専用のエディタで、コマンドだけで約 470 個ある。これを一度に取り込むと破綻する。

## 決定

- メモ帳相当の基本機能から作り、サクラエディタの操作感（キー割り当て、メニュー構成、表示）を再現する
- 進める順序は、メモ帳相当 → 巨大ファイル → 正規表現 → マクロ・プラグイン → サクラの機能の並列実装（[roadmap](../roadmap.md)）
- 初版に書式付きテキストは入れない
- 設定ファイルやキーワードファイルはサクラと互換にせず、独自の形式にする。サクラの設定の取り込みは、別の機能として後から足せる
- 仕様の参照元は、サクラエディタの上流のソースとヘルプ（zlib License）

## 影響

- 後のフェーズで実装する機能（範囲ごとの読み込み、正規表現、プラグイン）の入口は、Phase 1 で用意しておく
- 並列実装のフェーズに備えて、機能はコマンド単位で独立させる
