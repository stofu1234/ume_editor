# ADR-0003: 言語とライセンス

- 状態: 決定
- 日付: 2026-10-08

## 決定

- 言語は Rust
- ライセンスは MIT OR Apache-2.0（利用者がどちらかを選べるデュアルライセンス）

## 理由

- Rust: GC がなく、メモリ使用量が小さく、起動が速い。コンパイラが AI の書いたコードのミスを多く止める。テキスト処理の部品（ripgrep の検索ライブラリ、encoding_rs など）が揃っている
- MIT OR Apache-2.0: Rust のエコシステムで標準的。サクラエディタ（zlib）、Onigmo（BSD 系）、GPUI（Apache-2.0）のいずれとも両立する

## 第三者のコードの扱い

- 依存を追加するときは、MIT / Apache-2.0 と両立するライセンスか確認する。GPL 系（GPL・LGPL・AGPL）のものは使わない
- Zed のエディタ部分（GPL / AGPL のクレート）からはコードを写さない
- サクラエディタのコードを移植するときは、zlib License の条件に従い、元の著作権表示とライセンス文を残し、改変したことを明記する
- Onigmo は、同梱するソースに元のライセンス表示を残す
